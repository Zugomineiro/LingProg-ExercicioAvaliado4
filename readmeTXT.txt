Esse texto tem como objetivo explicar a compilação e a utilização do programa do exercício avaliado 4

- Compilação:
    Para compilar, abra o terminal na pasta onde esse arquivo README.txt se encontra e utilize o comando "make", isso irá
    gerar um arquivo "main.exe" (windows) ou "main"(linux) que poderá ser executado para iniciar o programa.
    OBS: o comando "make clean" limpa os arquivos compilados

- Utilização do programa:
    As opções do menu refletem os pedidos do enunciado.
    Para cada opção escolhida, irá aparecer um texto na tela dizendo para
    o usuário apertar ENTER para voltar, isso serve para que o menu não ofusque o texto que está sendo mostrado.

    O programa atualiza o custo de manutenção de um veiculo somente ao usar a opção "Atualizar quilometragem", portanto, é necessário
    usar essa opção para ter acesso a um custo de manutenção diferente de 0 e também para usar a opção "Calcular custo de manutencao".
    
    A opção "Ativar modo depuracao" cria dados de veiculos que podem ser usados para testes rápidos.
